# HydrangeaOS

`绣球操作系统`

stage1.asm (扇区1)
    ↓ 收集基本硬件信息
    ↓ 加载stage2 (扇区2-5)
stage2.asm (扇区2-5)  
    ↓ 收集更多硬件信息
    ↓ 保存到0x 区域
    ↓ 进入保护模式
    ↓ 跳转到system模块
system (内核)
    ↓ 读取0x 的硬件信息
    ↓ 根据实际硬件初始化驱动

## 当前阶段

`阶段2`

- 1.从0x7C00处读取了512字节的MBR文件，输出启动日志
- 2.进入保护模式
设置GDT
开启A20地址线
设置CRO，进入保护模式
- 3.加载内核
从磁盘读取内核到内存
跳转到内核
